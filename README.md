## 1. 系统概述  
本系统基于Qt框架开发，采用C/S架构，支持Windows、Linux、macOS等多平台运行。核心功能包括：  
  实时文本通信：支持多客户端消息广播，消息附带时间戳。  
  文件传输：支持断点续传与进度监控。  
  安全加密：集成SSL/TLS 1.3协议，提供端到端加密。  
  跨平台兼容：一次开发，多端部署。  


## 2. 环境要求  
  开发环境：Qt Creator 5.15（需安装`network`模块）。  
  运行环境：支持的操作系统包括Windows 10/11、Ubuntu 20.04+、macOS 12+。  
  网络配置：确保局域网内设备IP地址在同一网段。  


## 3. 安装与配置  
1. 下载代码：从GitCode仓库克隆源码：  
   git clone https://gitcode.com/scanf1/qt_big  

2. 编译项目：  
     使用Qt Creator打开`Server.pro`和`Client.pro`，点击`构建`→`重新构建项目`。  
     确保`.pro`文件中包含`QT += network`。  


## 4. 服务端使用指南  

4.1 启动服务端  
1. 运行编译生成的`Server`可执行文件。  
2. 主界面将自动加载本机所有可用IPv4地址（如`192.168.1.100`）。  

4.2 监听端口与IP配置  
1. 选择IP地址：从下拉框中选择`0.0.0.0`（监听所有网卡）或指定IP（如`127.0.0.1`）。  
2. 设置端口：输入端口号（需大于1024，如`8888`）。  
3. 启动监听：点击`监听`按钮，状态栏显示“关闭监听”表示成功。  

4.3 客户端连接管理  
  查看连接客户端：点击`查看连接数量`，显示当前在线客户端数。  
  强制断开客户端：点击`断开所有客户端`，清空连接列表。  

4.4 消息广播与文件传输  
  发送消息：在输入框输入文本，点击`发送`，消息将广播至所有客户端。  
  文件传输：点击`选择文件`，选择文件后点击`发送`，客户端将收到传输进度提示。  

4.5 安全设置  
  启用SSL加密：在服务端配置界面勾选`启用SSL`，并加载证书文件（需提前生成）。  
  日志审计：所有操作日志默认保存在`logs/server.log`。  


## 5. 客户端使用指南  

5.1 启动客户端  
运行编译生成的`Client`可执行文件。  

5.2 连接服务端  
1. 输入服务端信息：在IP地址栏输入服务端IP（如`192.168.1.100`），端口号需与服务端一致。  
2. 连接服务端：点击`连接`按钮，状态栏显示“连接成功”即完成。  

5.3 发送消息与文件  
  发送消息：在输入框输入内容，点击`发送`，消息将显示在服务端和其他客户端的聊天记录中。  
  上传文件：点击`选择文件`→`上传`，服务端将接收并存储文件。  

5.4 接收消息与文件  
  实时消息：新消息自动显示在聊天窗口，附带发送时间。  
  文件接收：收到文件时弹出保存对话框，选择路径后自动下载。  


## 6. 高级功能  

6.1 跨平台部署  
  Windows：直接运行编译生成的`.exe`文件。  
  Linux/macOS：通过终端执行：  
  ./Client --ip 192.168.1.100 --port 8888  

6.2 动态心跳检测  
服务端默认每30秒检测客户端连接状态，异常离线自动清理。  

6.3 安全审计与日志  
  日志路径：服务端日志：`logs/server.log`；客户端日志：`logs/client.log`。  
  查看日志：支持按时间范围检索关键操作记录。  

## 7. 常见问题与故障排除  

| 问题                   | 解决方法                                      
| 连接失败           | 检查防火墙是否放行端口，确认IP与端口正确。
| 文件传输中断   | 确保局域网带宽充足，重新发起传输。 
| 消息延迟高       | 检查网络拥塞情况，关闭非必要后台程序。 
| SSL证书错误    | 在服务端重新生成并分发证书至客户端。
